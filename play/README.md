# Interactive Demo

A lightweight interactive web project built with HTML, CSS, and JavaScript.

## Features

- Responsive landing page
- Modern dark UI
- Full-screen image viewer
- Audio playback support
- Lightweight and fast
- No frameworks required

## Project Structure

```
/
├── index.html
├── style.css
├── scare.jpg
├── scream2.mp3
└── README.md
```

## Getting Started

1. Download or clone the project.
2. Open `index.html` in any modern web browser.
3. Click the **Start** button to launch the experience.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

- Chrome
